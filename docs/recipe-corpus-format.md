# Recipe Corpus Format
Each recipe should be stored as one Markdown file in `data/recipes/`.

## Required Frontmatter
- `title`
- `description`
- `category`
- `tags`
- `total_time_minutes`
- `servings`
## Optional Frontmatter
- `cuisine`
- `source_label`
- `source_url`
- `calories`
- `protein`
- `fat`
- `carbs`
## Required Sections
- `## Ingredients`
- `## Instructions`
## Optional Sections
- `## Notes`
